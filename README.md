# 雨音計 (amaoto)

窓辺でマイクを向けると、雨音から「いま時間何ミリくらいの雨か」を推定し、Open-Meteo の現在降水量と並べて答え合わせするアプリ。

公開: https://amaoto.vercel.app

## 正直さの設計

- 屋根や窓の素材、マイクとの距離で雨音の大きさは何倍も変わる。だから **晴れの日の背景** と **雨の日1回の実測** で校正するまで数値は出さない。
- 雨量の幅を必ず出す。雨の校正が1回だけなら傾き p(E ∝ R^p)は 1.0〜1.6 と仮定し、その不確かさを幅に入れる(校正した雨量から離れるほど幅が開く)。雨量が2倍以上違う日に複数回録ると、p を最小二乗で当てる。
- 数値を出さない場面: 校正前 / 背景との差が 1 dB 未満(「約 x mm/h 未満か雨なし」と検出下限を言う) / 倍音の筋がある音が多い(声・音楽) / 0.5秒ごとの音量の変動が大きい(物音)。校正範囲から4倍以上外れたら「外挿」と明示する。
- Open-Meteo も観測ではなくモデル値(直前15分の合計 → 時間雨量に換算)。答え合わせの相手にも誤差があることを画面に書く。

## しくみ

1. AudioWorklet で 2048 サンプルずつ受け取り(自動音量・ノイズ除去はオフ)、ハン窓 FFT のパワースペクトルにする
2. 1〜8 kHz の帯域パワーを 0.5 秒ブロックごとに平均し、直近4秒の中央値をとる(ときどき鳴る音に引っぱられにくい)
3. 背景を引いた超過パワー E を、校正点を軸に E ∝ R^p で雨量へ戻す

中核はすべて `src/lib/` の純粋関数(`features.js` / `model.js` / `estimate.js` / `openmeteo.js` / `synth.js`)。

## 開発

```sh
pnpm install
pnpm dev      # http://localhost:5860
pnpm test     # Vitest
pnpm build
```

- 雨の日でなくても試せるよう、合成の雨音(`synth.js`: 減衰する雑音の粒を雨量に比例した数だけ降らせる)で動く **デモ** がある。デモの校正は保存しない。
- `window.__app` からヘッドレスで操作できる: `startDemo()`, `setDemoRate(r)`, `fastForward(sec)`, `recordBackground()`, `recordRain(ref)`, `estimate()`, `feed(wave, sr)`, `setLocation(lat, lon)`。

## 既知の限界

- 実際の雨の日にはまだ検証していない。しきい値(倍音フレーム 20%、変動 0.6、下限 1 dB)は合成音で決めたもの。
- 雨の中で話し続ける・テレビをつけているなど、半分以上の時間鳴る音は雨量を多めに見せる。
- 校正は端末・場所ごと。窓を開け閉めしたりマイクを動かしたら取り直しが必要。
